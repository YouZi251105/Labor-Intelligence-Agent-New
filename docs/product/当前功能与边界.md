# 当前功能与边界

版本：0.2.0 Demo
更新日期：2026-11-03

## 1. 产品定位

劳务通面向基层劳动者，围绕劳动纠纷提供咨询、案件整理、证据准备、合同风险提示、法律文书草稿和律师协助入口。

当前版本的目标是验证完整业务链路，而不是直接承担正式法律服务或生产存证。

## 3. AI 运行方式

### 本地演示规则

未配置千问 API Key 时，系统通过关键词和规则完成：

- 纠纷类型识别
- 劳动关系或劳务关系初判
- 下一步建议
- 上下文提示

回复中会明确标记“本地演示规则回复”。

### 千问模型

配置 `QIANWEN_API_KEY` 后，系统调用千问兼容接口生成回复。如果调用失败，会自动回退到本地演示规则。

### 决策树与规则包

案件流程由独立的版本化规则包驱动，服务代码只负责解释选项、前置条件和期限提示，不在业务分支中写死具体路径。

当前内置规则包状态为 `pending_review`，页面会明确显示“规则待复核”。期限规则目前只展示待复核提示，不生成正式截止日期。

当前支持：

- 一个节点配置多个候选路径。
- `evidence_ready` 和 `lawyer_assigned` 前置条件。
- 选择结果、下一步说明和阻止原因。
- 将选择路径写入案件上下文。
- 保留旧 `target_stage` 接口兼容。

当前管理端已提供纯中文 Excel 模板下载/导入、当前版本 Excel 导出、AI 辅助生成草稿、可视化拖拽组合、Word 复核稿和只读复核，支持：

- `draft → pending_review → approved → published → retired`
- 驳回后重新编辑和提交
- 发布新版本时自动停用同包旧版本
- 运行时只使用最新已发布版本，没有发布版本时回退内置包

规则包填写说明见 [规则包 Excel 填写说明](../admin/规则包Excel填写说明.md)。

Excel 只使用中文阶段名称、节点名称和处理选项名称关联，内部标识由系统自动生成。JSON 继续作为系统内部存储和 API 契约格式，但不在普通管理员前端提供导入、下载或原文编辑入口。

### 受约束流程积木

可视化设计器只提供平台批准的五类积木：阶段、选择、证据条件、律师条件和结束。内容人员不能创建任意积木类型或自由表达式。

- 结束块不能有出口。
- 证据条件块必须包含证据满足和兜底路径。
- 律师条件块必须包含律师已分配和兜底路径。
- 所有节点必须从起点可达。
- 运行时根据 `workflow_node_id` 定位具体积木，再根据节点配置得到业务阶段。

## 4. 证据能力边界

当前可以：

- 检查扩展名和基础文件头。
- 计算 SHA256。
- 防止同案件重复上传。
- 根据文件名、类型和已提取文本进行材料分类。
- 按纠纷类型提示材料缺口。
- 提取 TXT、可复制文本 PDF 和 DOCX 的内容。
- 通过 OCR Provider 处理图片；当前环境未配置 OCR 引擎时明确标记为待识别。
- 对 JPG、JPEG、PNG、WebP 做初步真实性筛查，包括 EXIF 编辑软件痕迹、重压缩异常、拼接边界和马赛克/涂抹网格；明显异常图片不会进入正式材料列表。
- 删除未被法律文书引用的相关材料，并保留删除审计记录。

当前不能：

- 在没有 OCR 服务时识别图片和扫描版 PDF。
- 判断材料内容一定真实。
- 通过初步筛查替代司法鉴定或保证 100% 识别伪造。
- 鉴定印章、签名或合同真伪。
- 提供司法鉴定或正式电子存证。
- 直接删除已经纳入法律文书证据目录的材料。

## 5. 文书边界

当前生成的文书是待确认草稿，不能直接视为可提交的正式法律文件。

当前支持 DOCX/PDF 导出、文书编辑、版本记录和证据目录。

当前不提供：

- 法院或仲裁系统自动立案
- 电子签章
- 律师签署
- 正式送达

## 6. 律师服务边界

当前律师账号由演示数据或管理员维护，不开放公开注册。

当前支持查看分配案件、提交律师意见、登记服务记录和收益台账。

律师服务已支持两类介入：

- 被动介入：用户预约律师、律师在工作台受理或拒绝、双方进入留存式咨询对话，对话记录结束后保留可查。
- 主动介入：案件准备仲裁或网上立案前，律师复核最终材料并给出结论（可以立案 / 需要补充材料 / 暂不建议立案），用户根据结论选择自行办理或平台协助。

律师服务仍不包含：

- 在线订单
- 咨询收费
- 自动分账
- 提现
- 评价体系
- 消息实时推送（当前需刷新页面查看新消息）

## 7. 后续方向

1. 配置生产 OCR 服务并接入扫描版 PDF。
2. 案件状态机和程序期限提醒。
3. 正式律师入驻审核和资质材料上传。
4. 在线订单、支付、分账、提现和评价。
5. 生产对象存储、迁移、监控和备份恢复。
6. 方言语音识别和更丰富的沟通训练。
7. 移动端体验和重点用户测试。
