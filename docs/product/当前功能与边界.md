# 当前功能与边界

版本：0.1.0 Demo  
更新日期：2026-11-01

## 1. 产品定位

劳务通面向基层劳动者，围绕劳动纠纷提供咨询、案件整理、证据准备、合同风险提示、法律文书草稿和律师协助入口。

当前版本的目标是验证完整业务链路，而不是直接承担正式法律服务或生产存证。

## 3. AI 运行方式

### 本地演示规则

未配置千问 API Key 时，系统通过关键词和规则完成：

- 纠纷类型识别
- 劳动关系或劳务关系初判
- 下一步建议
- 上下文提示

回复中会明确标记“本地演示规则回复”。

### 千问模型

配置 `QIANWEN_API_KEY` 后，系统调用千问兼容接口生成回复。如果调用失败，会自动回退到本地演示规则。

## 4. 证据能力边界

当前可以：

- 检查扩展名和基础文件头。
- 计算 SHA256。
- 防止同案件重复上传。
- 根据文件名、类型和已提取文本进行材料分类。
- 按纠纷类型提示材料缺口。
- 提取 TXT、可复制文本 PDF 和 DOCX 的内容。
- 通过 OCR Provider 处理图片；当前环境未配置 OCR 引擎时明确标记为待识别。

当前不能：

- 在没有 OCR 服务时识别图片和扫描版 PDF。
- 判断材料内容一定真实。
- 鉴定印章、签名或合同真伪。
- 提供司法鉴定或正式电子存证。

## 5. 文书边界

当前生成的文书是待确认草稿，不能直接视为可提交的正式法律文件。

当前后端支持 DOCX/PDF 导出和版本记录，前端编辑联调尚未完成。

当前不提供：

- 法院或仲裁系统自动立案
- 电子签章
- 律师签署
- 正式送达

## 6. 律师服务边界

当前律师账号由演示数据或管理员维护，不开放公开注册。

当前支持查看分配案件，不包含：

- 在线订单
- 咨询收费
- 自动分账
- 提现
- 评价体系

## 7. 后续方向

1. 配置生产 OCR 服务并接入扫描版 PDF。
2. 完成前端 PDF/DOCX 上传、文书编辑、版本切换和下载联调。
3. 案件状态机和程序期限提醒。
4. 法条、规则、模板和机构入口的内容管理。
5. 律师意见、文书修改和服务记录。
6. 材料加密、对象存储和审计查询。
7. 移动端体验和重点用户测试。
