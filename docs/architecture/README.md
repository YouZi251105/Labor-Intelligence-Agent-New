# 架构说明

当前项目采用模块化单体架构：

```text
Vue 3 Web
    |
Nginx
    |
FastAPI
    |-- PostgreSQL + pgvector
    |-- Redis / Celery
    |-- MinIO
    `-- AI / OCR Provider
```

首期不拆分微服务。案件、证据、文书、律师和审计模块在同一个 API 服务内按领域分包，通过清晰的 service 和 repository 边界保持可拆分性。

## 已初始化

- 前后端目录与依赖管理。
- API 版本前缀 `/api/v1`。
- 健康检查和统一配置读取。
- PostgreSQL 异步连接边界。
- Celery 任务入口。
- 对象存储环境配置。
- Vue 路由、状态管理和法律风格工作台。
- JWT 登录、用户角色和对象级案件访问控制。
- 案件、会话、消息、证据、文书、律师档案和审计日志模型。
- 本地 SQLite 演示数据库与自动演示数据。
- 多轮咨询上下文、证据材料分类与缺口提示。
- 合同文本风险审查和三类法律文书草稿。
- 管理员案件分配和律师工作台。
