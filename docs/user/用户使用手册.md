# 劳务通用户使用手册

适用对象：劳动者用户  
版本：0.1.0 Demo

## 1. 使用前准备

项目需要在 Windows 环境运行，并具备 Python、Node.js 和 npm。依赖安装完成后，双击根目录 `start.bat` 即可启动。

浏览器访问：<http://127.0.0.1:5173/>

## 2. 登录与注册

### 演示登录

使用以下账号体验：

- 用户名：`demo`
- 密码：`Demo123!`

登录页也提供劳动者、律师和管理员演示账号快捷填充。

### 注册

点击“没有账号，立即注册”，填写：

- 用户名
- 显示名称
- 密码

注册成功后会自动登录。

## 3. AI 法律咨询

登录后默认进入 AI 法律咨询页面。

### 首次咨询

1. 在输入框描述问题，例如：
   > 我在工地干了三个月，没有签合同，老板拖欠两个月工资。
2. 点击“发送问题”或按 Enter。
3. 系统自动创建案件，并保存第一条咨询。
4. AI 回复会给出问题分类、初步关系和下一步建议。

### 继续咨询

系统会把历史消息作为当前案件上下文。后续可以补充：

- 对方主体和联系方式
- 工作地点、岗位和入职时间
- 工资标准和拖欠金额
- 是否签合同
- 现有聊天记录、工资流水和考勤

### 快捷问题

首次咨询页面提供：

- 拖欠工资
- 突然被辞退
- 没有签合同
- 工伤或受伤

点击后会填入输入框，仍需用户确认并发送。

## 4. 我的案件

点击左侧“我的案件”查看全部个人案件。

案件卡片展示：

- 纠纷类型
- 当前阶段
- 用工地点
- 最近更新时间

点击卡片进入案件工作台。

### 新建案件

点击“新建案件”，填写：

- 案件名称
- 纠纷类型
- 用工所在地
- 基本情况

提交后进入案件详情。

## 5. 案件工作台

案件详情包含五个页签：

1. 案件概览
2. 咨询记录
3. 证据材料
4. 合同审查
5. 法律文书

案件顶部展示案件编号、纠纷类型、当前阶段、关系类型和律师分配状态。

### 案件概览

展示案件事实、当前建议、地点、更新时间和承办律师状态。

### 咨询记录

展示该案件的历史问答。可以继续输入消息，系统会带上当前案件上下文。

## 6. 证据材料

支持上传：

- JPG、JPEG、PNG、WebP
- PDF
- TXT
- DOC、DOCX

单个文件不超过 20MB。

上传后系统会：

- 检查扩展名和基础文件格式。
- 计算 SHA256。
- 检查同一案件是否重复上传。
- 按文件名、类型和文本内容尝试分类。
- 根据纠纷类型提示缺少的材料类别。

材料分类包括合同、聊天记录、工资记录、考勤、医疗材料、社保材料、结算单和其他材料。

### 注意

- SHA256 只表示文件是否发生变化，不表示材料内容必然真实。
- 当前版本不提供正式 OCR。
- PDF、Word 和图片可保存，但暂不保证自动识别全部文字。
- 正式材料应保留原件。

## 7. 合同审查

进入“合同审查”，粘贴合同条款后点击“开始审查”。

当前演示规则会提示：

- 自愿放弃社会保险
- 单方随时解除
- 收取押金
- 违约金
- 工资约定不明确
- 部分关键条款缺失

结果分为低、中、高风险。

系统不会判断印章、签名或合同是否伪造。审查结果仅用于风险提示。

## 8. 法律文书

进入“法律文书”，可以生成：

- 协商和解协议
- 劳动仲裁申请书
- 民事起诉状

生成后可以：

- 在线预览
- 下载 TXT 文件

文书使用已填写的案件事实和已上传证据目录。当前版本不会自动生成 DOCX 或 PDF，也不会直接提交到法院或仲裁平台。

正式使用前必须核对：

- 双方主体
- 金额
- 请求事项
- 事实经过
- 证据目录
- 管辖机构和提交时限

## 9. 律师协助

管理员分配律师后，案件详情的“承办律师”状态会发生变化。

当前劳动者端可以查看律师是否已分配，律师会通过律师工作台查看案件。在线聊天、支付和服务评价尚未实现。

## 10. 其他页面

- 模拟对话：当前为功能占位，后续接入角色训练和评分。
- 维权帮助：当前为功能占位，后续接入仲裁委、法院入口和本站律师资料。

## 11. 隐私与安全

- 不要上传与案件无关的身份证、银行卡或家庭信息。
- 演示规则会读取用户输入并保存到本地数据库。
- 配置千问 API Key 后，咨询内容可能发送给第三方模型服务。
- 正式部署前需要完成隐私政策、授权、加密存储和访问审计。

## 12. 常见问题

### 页面提示“服务未连接”

检查后端窗口是否仍在运行，并访问：

<http://127.0.0.1:8000/api/v1/health>

### 上传被拒绝

检查文件格式、大小和内容是否与扩展名一致。已上传的相同文件不能重复上传。

### 没有看到案件

确认当前登录账号是否正确。普通用户只能查看自己的案件。

### AI 显示“演示规则”

表示当前没有配置千问 API Key，系统正在使用本地规则回复。
