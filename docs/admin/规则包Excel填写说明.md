# 规则包 Excel 填写说明

适用对象：法律内容负责人、规则复核人员、平台管理员

## 1. 使用方式

规则包 Excel 是面向非技术人员的配置入口。填写时只需要使用中文阶段名称、节点名称和处理选项名称，不需要填写内部 ID、英文枚举或系统编号。

可以从两个位置取得模板：

- 管理后台 → 规则包中心 → 下载 Excel 模板
- 文档模板：[规则包填写模板](../templates/规则包填写模板.xlsx)

填写完成后在规则包中心点击“导入 Excel”。系统会自动生成内部标识，创建草稿并进入校验、送审、批准和发布流程。

## 2. 填写顺序

1. 在“基础信息”填写规则版本、适用地区、起始节点名称和免责声明。
2. 在“案件阶段”填写阶段名称和阶段说明。
3. 在“流程节点”填写节点名称、所属阶段、节点类型和画布位置。
4. 在“处理路径”填写从哪个节点出发、用户看到的处理选项、下一步去哪个节点。
5. 需要条件时，在“前置条件”中选择起始节点和处理选项名称。
6. 需要期限时，在“期限规则”中选择起始节点和处理选项名称。
7. 保存为 `.xlsx` 后在管理端导入。

## 3. 工作表说明

| 工作表 | 填写内容 |
|---|---|
| 填写说明 | 无需修改 |
| 基础信息 | 规则版本、适用地区、起始节点名称、免责声明 |
| 案件阶段 | 阶段名称、阶段说明 |
| 流程节点 | 节点名称、所属阶段、节点类型、横坐标、纵坐标 |
| 处理路径 | 起始节点、顺序、处理选项名称、选项说明、去向节点、选择结果、下一步操作 |
| 前置条件 | 起始节点、处理选项名称、条件类型、提示文案 |
| 期限规则 | 起始节点、处理选项名称、期限标题、期限说明、法律依据、起算事件、计算方式、复核状态 |
| 系统信息 | 系统自动维护的隐藏信息，不要修改 |
| 数据字典 | 可填写值参考，不需要修改 |

## 4. 中文名称关联规则

- 阶段名称必须唯一。
- 节点名称必须唯一。
- 同一节点下的处理选项名称必须唯一。
- “所属阶段”必须与“案件阶段”中的阶段名称完全一致。
- “起始节点”必须与“流程节点”中的节点名称完全一致。
- “去向节点”必须与“流程节点”中的节点名称完全一致。
- 前置条件和期限规则通过“起始节点 + 处理选项名称”关联路径，不需要填写路径 ID。
- 基础信息中的“起始节点名称”必须对应一个流程节点。

## 5. 节点类型

节点类型只能选择：

- 阶段
- 选择
- 证据条件
- 律师条件
- 结束

横坐标和纵坐标决定积木在可视化画布中的初始位置。留空时系统会自动排布，导入后仍可在管理端拖拽调整。

## 6. 前置条件和期限

前置条件可选择：

- 始终可用
- 证据已满足
- 律师已分配

如果一个处理选项没有单独填写前置条件，系统会默认设置为“始终可用”。

期限计算方式当前只支持“人工复核”。不得在 Excel 中填写正式截止日期或尝试使用公式。

## 7. 导入与复核

1. 在规则包中心点击“导入 Excel”。
2. 系统检查工作表、中文名称引用、顺序、条件和规则结构。
3. 成功后生成新的“草稿”，不会直接上线。
4. 打开草稿后可以继续拖拽积木、调整节点和路径。
5. 提交复核；批准后由有权限的管理员发布。
6. 需要线下复核时，可下载 Word 复核稿。

导入错误会标记工作表、单元格和行号，例如：

```text
处理路径!E5：去向节点“不存在的节点”不存在
处理路径!C8：节点“整理证据”下的处理选项名称重复
前置条件!A9：找不到对应的节点和处理选项
```

按提示修正后重新导入。

## 8. 安全限制

- 单文件最大 5 MiB，只接受 `.xlsx`。
- 不执行宏、公式、外部链接或脚本。
- 不允许合并单元格、自行新增工作表或修改固定表头。
- 单工作表有效数据最多 2000 行。
- 导入内容仍需完成送审、批准和发布，不会绕过法律复核。

## 9. 查看与归档

规则包中心可以将当前版本导出为 Excel，用于线下复核、版本比对和归档。导出后再导入会生成新草稿，不会覆盖原发布版本。

系统内部仍使用 JSON 保存和执行规则，但普通管理员不需要查看或编辑 JSON。
