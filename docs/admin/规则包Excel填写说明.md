# 规则包 Excel 填写说明

适用对象：法律内容负责人、规则复核人员、平台管理员

## 1. 使用方式

规则包 Excel 是非技术人员的录入中间层。填写完成后由系统转换为规则包草稿，再进入送审、批准和发布流程。Excel 不是运行时格式，JSON 仍是系统内部唯一机器格式。

可以从两个位置取得模板：

- 管理后台 → 规则包中心 → 下载 Excel 模板
- 文档模板：[规则包填写模板](../templates/规则包填写模板.xlsx)

请始终使用 `.xlsx` 文件。不要使用 `.xls`、`.xlsm`，也不要自行增加工作表、列或修改表头。

## 2. 填写顺序

1. 在“基础信息”中确认包标识、版本、适用地区、起始节点和免责声明。
2. 在“阶段”中填写案件的业务阶段。
3. 在“节点”中填写流程节点，并选择节点所属阶段。
4. 在“路径”中填写每个节点可选择的去向、结果说明和下一步。
5. 需要证据或律师条件时，在“前置条件”中用路径ID关联。
6. 填写期限规则时，在“期限规则”中用路径ID关联。
7. 导入前检查阶段ID、节点ID和路径ID没有重复。

## 3. 工作表说明

| 工作表 | 必填内容 |
|---|---|
| 填写说明 | 无需修改 |
| 基础信息 | 结构版本、包标识、版本、地区、复核状态、免责声明、起始节点 |
| 阶段 | 阶段ID、显示名称、说明 |
| 节点 | 节点ID、所属阶段、节点名称；使用可视化设计器时补全积木类型和坐标 |
| 路径 | 路径ID、来源节点ID、顺序、选项名称、目标节点ID、目标阶段、结果说明、下一步 |
| 前置条件 | 路径ID、条件类型、提示文案 |
| 期限规则 | 路径ID、期限ID、标题、说明、法律依据、起算事件、计算方式、复核状态 |
| 数据字典 | 系统参考数据，不需要填写 |

浅红色单元格表示可以填写。深红色表头和数据字典由平台维护。

## 4. ID 与引用规则

- 阶段ID、节点ID和路径ID只能使用字母、数字、下划线、点和短横线。
- 路径ID在整个规则包内唯一。
- 节点ID在整个规则包内唯一。
- 同一来源节点下，“顺序”必须是互不重复的正整数。
- “目标节点ID”必须已经在“节点”工作表中存在。
- “目标阶段”必须与目标节点所属阶段完全一致。
- “前置条件”和“期限规则”的路径ID必须在“路径”工作表中存在。
- 起点节点必须已经填写，且不能是结束积木。

## 5. 受约束字段

积木类型可选择：

- 阶段
- 选择
- 证据条件
- 律师条件
- 结束

前置条件可选择：

- 始终可用
- 证据已满足
- 律师已分配

期限计算方式当前只支持“人工复核”。不得在 Excel 中填写正式截止日期或试用公式。

## 6. 导入与复核

1. 在规则包中心点击“导入 Excel”。
2. 系统检查文件类型、大小、工作表、表头、引用和规则结构。
3. 成功后生成新的“草稿”，不会直接上线。
4. 打开草稿，在可视化流程中检查内容和节点去向。
5. 提交复核；批准后由有权限的管理员发布。
6. 发布新版本时，同包旧发布版本自动停用。

导入失败时，错误会标记工作表、单元格和行号，例如：

```text
路径!F5：目标节点 evidence 不存在
路径!C8：节点 intake 下的顺序 2 重复
前置条件!B9：条件类型 approval 不在允许范围内
```

按提示逐项修正后重新导入。不要通过改名工作簿或删除错误行绕过校验。

## 7. 安全限制

- 单文件最大 5 MiB。
- 只接受 `.xlsx`。
- 不执行宏、公式、外部链接或脚本。
- 公式单元格会被拒绝。
- 不允许合并单元格、自行新增列或修改系统表头。
- 导入内容仍需完成送审、批准和发布，不会跳过法律复核。

## 8. 查看与留档

规则包中心可以导出当前选中版本的 Excel，用于线下复核、版本比对和归档。导出后再导入会生成新的草稿，不会覆盖原发布版本。
