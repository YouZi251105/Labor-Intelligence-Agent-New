# 劳务通管理员使用手册

适用对象：平台管理员  
版本：0.2.0 Demo

## 1. 登录与导航

管理员使用独立账号登录，登录后自动进入管理后台。

演示账号统一记录在 [演示账号](../demo/演示账号.md) 中，登录页不直接展示账号和密码。

管理后台左侧包含以下子菜单：

- 管理总览
- 用户管理
- 律师管理
- 案件分配
- 规则复核
- 材料管理
- 审计日志
- 收益管理

## 2. 管理总览

管理总览展示：

- 用户、案件、证据、文书、律师和实名待核验总量
- 近 7 天新增用户与新增案件趋势
- 纠纷类型构成
- 案件阶段分布
- 待核验用户、待审核律师和待分配案件提醒
- 最近平台操作审计

总览以运营数据大屏展示，图表数据仅来自管理端聚合接口，不返回案件事实或个人敏感字段。完整明细仍在对应管理页处理。

## 3. 用户管理

从“管理后台 → 用户管理”进入。

列表展示用户名、显示名称、角色、手机号、创建时间和账号状态，并支持：

- 按用户名、姓名或手机号搜索。
- 按劳动者、律师、管理员筛选。
- 按正常、停用状态筛选。
- 查看用户脱敏详情、实名核验状态和身份证号脱敏值。
- 修改劳动者的实名核验状态。
- 重置用户密码。
- 停用或恢复普通用户账号。

密码重置和账号状态变更都会写入审计日志。

当前操作人不能停用自己的账号。管理员账号停用需先完成交接，避免平台失去可用管理员。

## 4. 律师管理

从“管理后台 → 律师管理”进入。

管理员可以查看律师的显示名称、用户名、执业证号、擅长领域和状态，并修改：

- `pending`：待审核
- `active`：正常
- `suspended`：暂停并停用账号

公开律师注册和资质材料上传尚未开放。

## 5. 案件分配

从“管理后台 → 案件分配”进入。

1. 找到需要处理的案件。
2. 在下拉框中选择律师。
3. 点击“分配”。
4. 分配成功后，案件会出现在对应律师的工作台。

点击“查看”可以进入案件详情。管理员对案件业务内容只读，不能代替劳动者发送咨询、上传证据、修改事实、推进流程或生成文书。

## 6. 规则包、规则复核、材料、审计和收益

### 6.1 规则包 Excel 流程

从“管理后台 → 规则包中心”进入。

1. 点击“下载 Excel 模板”，取得标准 `.xlsx` 工作簿。
2. 按 [规则包 Excel 填写说明](规则包Excel填写说明.md) 填写基础信息、阶段、节点、路径、条件和期限。
3. 点击“导入 Excel”，系统校验通过后创建新的草稿版本。
4. 在可视化画布中检查结果；可继续从左侧拖拽阶段、选择、证据条件、律师条件或结束积木，也可拖动已有积木调整位置。
5. 点击“提交复核”，由复核人批准或驳回。
6. 批准后点击“发布”；同包旧发布版本自动停用。
7. 需要线下复核或留档时，选择版本并点击“导出当前 Excel”或“下载 Word 复核稿”。

Excel 导入不会直接上线，也不能绕过送审、批准和发布。导入失败时会显示工作表、单元格和行号；按提示修正后重新导入。

JSON 仅作为系统内部存储和 API 契约格式保留，不在管理员前端提供导入、下载或原文编辑入口。

### 6.2 AI 辅助生成草稿

1. 点击“AI 生成草稿”。
2. 用中文描述需要新增或调整的流程，例如“增加工伤咨询入口，先判断是否完成工伤认定，再分别引导申请待遇或转律师复核”。
3. 点击“生成规则草稿”。
4. AI 会以当前内置流程为基础生成草稿，并自动补齐可视化画布布局。
5. AI 结果必须继续执行结构校验和人工复核校验，不会直接发布。

### 6.3 其他管理能力

- “规则复核”查看六类纠纷的演示证据规则，并把复核状态改为待复核、已通过或需修订。
- “材料管理”只查看材料文件名、类别、大小和提取状态，不展示材料正文。
- “审计日志”查看最近操作，不展示材料正文、密码或完整身份证号。
- “收益管理”查看律师服务记录和收益台账，并将收益状态从待确认推进到已确认、已结算。

## 7. 权限说明

- 管理员可以查看全部案件。
- 管理员可以分配案件、管理账号和审核平台配置。
- 管理员可以只读查看咨询、证据和文书，但不能以劳动者身份写入业务数据。
- 管理员不能从管理端进入律师工作台。
- 管理员访问案件和材料时应遵守最小权限原则。
- 正式环境中的管理员操作必须保留完整审计日志。

## 9. 演示数据安全

演示账号密码只能用于本地开发。正式部署前必须：

- 修改所有演示密码。
- 更换 `SECRET_KEY`。
- 配置生产数据库和对象存储。
- 关闭演示数据自动初始化。
- 设置 HTTPS、备份和访问审计。
