# 劳务通管理员使用手册

适用对象：平台管理员  
版本：0.1.0 Demo

## 1. 登录

演示账号：

- 用户名：`admin`
- 密码：`Admin123!`

登录后进入管理后台。

## 2. 数据概览

首页展示：

- 用户数量
- 案件数量
- 证据数量
- 文书数量

当前数据直接来自本地 SQLite 演示库。

## 3. 案件分配

在“案件与律师”区域：

1. 找到需要处理的案件。
2. 在下拉框中选择律师。
3. 点击“分配”。
4. 分配成功后，案件会出现在对应律师的工作台。

点击“查看”可以进入案件详情。

## 4. 用户管理

用户列表展示：

- 用户名
- 显示名称
- 角色

### 重置密码

点击“重置密码”，输入至少 8 位的新密码。

密码重置会写入审计日志。

## 5. 律师管理

当前管理员可以查看律师：

- 显示名称
- 用户名
- 执业证号
- 擅长领域
- 状态

管理员可以在“律师”页修改律师状态：

- `pending`：待审核
- `active`：正常
- `suspended`：暂停并停用账号

公开律师注册和资质材料上传尚未开放。

## 6. 规则、材料、审计和收益

- “规则”页查看六类纠纷的演示证据规则，把复核状态改为待复核、已通过或需修订。
- “材料”页只查看材料文件名、类别、大小和提取状态，不展示材料正文。
- “审计”页查看最近操作，不显示材料正文或密码。
- “收益”页查看律师服务记录和收益台账，并将收益状态从待确认推进到已确认、已结算。

## 7. 权限说明

- 管理员可以查看全部案件。
- 管理员可以分配案件。
- 管理员可以重置用户密码。
- 管理员访问案件和材料时应遵守最小权限原则。
- 正式环境中的管理员操作必须记录完整审计日志。

## 8. 当前限制

尚未实现：

- 律师入驻审核工作流
- 材料删除、隔离和恢复操作页
- 正式法律内容管理版本发布流程
- 在线订单、支付、自动分账和提现
- 系统配置和模型参数管理页

## 9. 演示数据安全

演示账号密码只能用于本地开发。正式部署前必须：

- 修改所有演示密码。
- 更换 `SECRET_KEY`。
- 配置生产数据库和对象存储。
- 关闭演示数据自动初始化。
- 设置 HTTPS、备份和访问审计。
