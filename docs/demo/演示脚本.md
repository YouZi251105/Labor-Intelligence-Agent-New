# 劳务通现场演示脚本

建议时长：8–10 分钟  
版本：0.1.0 Demo

## 1. 演示前检查

1. 双击根目录 `start.bat`。
2. 确认前端打开：<http://127.0.0.1:5173/>
3. 确认后端健康：<http://127.0.0.1:8000/api/v1/health>
4. 准备一段欠薪描述和一段合同文本。

## 2. 登录与产品定位（1 分钟）

使用 `demo / Demo123!` 登录。

讲解要点：

- 面向基层劳动者。
- 覆盖咨询、案件、证据、合同、文书和律师协助。
- 首期聚焦中国法域和中文。

## 3. AI 咨询（2 分钟）

输入：

> 我在工地干了三个月，没有签合同，老板拖欠两个月工资，现在把我踢出工作群了。

讲解：

- 系统自动创建案件。
- 识别欠薪类型和劳动关系方向。
- 给出证据和下一步建议。
- 历史对话保存在同一案件上下文中。

## 4. 案件与证据（2 分钟）

进入“我的案件”，打开案件。

切换到“证据材料”，上传一份 TXT：

```text
9月工资5000元，10月工资5000元，尚未支付。
老板说下周再发。
```

讲解：

- 文件格式和内容检查。
- SHA256。
- 自动分类为工资记录。
- 按欠薪规则提示仍需补充聊天记录、合同等材料。

## 5. 合同审查（1 分钟）

进入“合同审查”，粘贴：

> 甲方可以随时解除合同，乙方自愿放弃社会保险，工资另行约定。

讲解：

- 提示单方解除、放弃社保和工资不明确。
- 结果是风险提示，不是合同真伪鉴定。

## 6. 文书生成（1 分钟）

进入“法律文书”，点击“劳动仲裁申请书”。

讲解：

- 文书使用案件事实和证据目录。
- 生成的是待确认草稿。
- 可预览和下载 TXT。
- 正式提交前必须核对主体、金额、管辖和时效。

## 7. 管理员分配律师（1 分钟）

退出，使用 `admin / Admin123!` 登录。

在“管理后台 → 案件与律师”中：

1. 选择“李律师”。
2. 点击“分配”。
3. 打开案件确认已分配。

讲解：

- 管理员可以查看用户和案件。
- 可以重置密码。
- 可以人工分配案件。

## 8. 律师工作台（1 分钟）

退出，使用 `lawyer / Lawyer123!` 登录。

讲解：

- 律师只能查看分配给自己的案件。
- 可以进入案件查看咨询、证据和文书。
- 可以提交律师意见、登记服务记录和创建待确认收益。
- 当前版本不包含在线支付、自动分账和在线沟通。

## 9. 模拟对话与维权帮助（1 分钟）

1. 进入“模拟对话”，选择案件和“单位负责人”角色。
2. 输入工资沟通表达，展示综合评分和改进建议。
3. 进入“维权帮助”，展示仲裁、法院、法律援助入口和本站律师。
4. 说明实名资料只保存脱敏值、哈希和核验状态。

## 10. 管理员规则与审计（1 分钟）

1. 使用管理员账号进入“管理后台”。
2. 切换“规则”“材料”“审计”“收益”页签。
3. 展示规则复核、材料元数据、审计记录和收益状态流转。
4. 强调聚合话题不返回任何用户原始咨询。

## 11. 收尾说明

重点强调：

1. 当前是端到端业务 Demo。
2. AI 未配置模型时使用本地演示规则。
3. 正式使用前需要法律规则复核、生产 OCR、数据安全和部署验证。
4. 平台不会把 AI 结果直接当成律师意见。

## 12. 演示后重置

如需恢复干净演示数据，停止后端后删除：

```text
backend/data/demo.db
backend/data/uploads/
```

再次启动会自动生成演示账号和初始案件。
