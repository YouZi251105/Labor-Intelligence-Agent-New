# 来源核验与专业复核流程

更新日期：2026-11-03

## 1. 目的

本流程用于管理平台中的法条、类案、引用关系、提示词规则和帮助资源，确保进入正式知识库的内容：

- 能找到可追溯的官方来源。
- 法条名称、条款、正文、生效状态与官方文本一致。
- 类案有完整案号、裁判日期、来源文件和裁判要旨。
- 类案与法条的引用关系真实、相关，不是只靠关键词相近。
- 专业复核人能够独立判断、签字并留下意见。
- 法律修订、案例失效或资源失效时能够及时撤回。

本流程不代替专业法律意见。平台展示内容仍应明确其信息参考属性，并保留人工咨询入口。

## 3. 角色与责任

### 3.1 内容采集人

负责整理候选内容、补录基础字段、查找官方来源，并填写来源候选材料。

内容采集人可以由运营、产品助理或经过培训的内容人员承担，但不得自行把内容标记为“已发布”。

### 3.2 来源核验人

负责实际打开官方页面、下载或留存原始文件，并逐字核对：

- 法律文件名称、发布机关、文号、条款号和原文。
- 公布日期、生效日期、失效日期和现行效力。
- 类案案号、法院、裁判日期、裁判结果和裁判要旨。
- 帮助电话能否拨通、视频能否访问。

来源核验人必须填写真实姓名或可追溯工号，不能只填写“已核对”“确认无误”。

### 3.3 专业复核人

负责从法律专业角度判断：

- 该法条是否适用于目标争议类型。
- 通俗说明是否改变或扩大了法律含义。
- 类案与当前问题是否具有可比性。
- 裁判要旨是否准确，是否把个案结果误写成普遍规则。
- Prompt 是否存在诱导确定性结论、错误估算或遗漏风险提示的问题。

专业复核人应具备法律专业背景或由合作法律团队指定。原则上，专业复核人与来源核验人不能是同一人。

### 3.4 发布审批人

负责检查发布门禁、版本号、适用范围、展示文案和撤回机制。发布审批人不能代替来源核验或专业复核。

### 3.5 四眼原则

一条内容至少经过两个独立角色：

1. 来源核验人核对原始材料。
2. 专业复核人独立判断法律内容。

如果因为人员不足需要同一人临时兼任，必须记录原因、补复核计划和审批人，不能默认长期合并角色。

## 4. 官方来源优先级

### 4.1 法条

优先级从高到低：

1. 国家法律法规数据库。
2. 全国人大、国务院、最高人民法院、最高人民检察院等官方网站。
3. 国务院部门、省级人大常委会、省级政府和司法行政机关官网。
4. 地方政府或人社部门官网。

地方性规定、司法解释、部门规章和规范性文件应分别标明类型，不能混写成“法律”。

### 4.2 类案

优先级从高到低：

1. 中国裁判文书网或法院官方公开页面。
2. 法院、检察院、司法行政机关发布的典型案例、指导案例或公报案例。
3. 最高人民法院案例库、人民法院案例库等官方案例渠道。
4. 官方新闻发布会、官方公众号或官方出版物。

新闻聚合页、自媒体文章、百科和二手转载只能用来发现线索，不能作为最终来源。

### 4.3 帮助资源

法律援助电话、仲裁机构、法院诉讼入口和视频资源应优先使用政府、司法行政机关、法律援助中心、法院或发布平台的官方页面。

电话必须实际拨测，视频必须实际打开。不能把“搜索结果里存在”当作“仍然有效”。

## 5. 必填字段

### 5.1 法条

法条至少应具备：

- 法条 ID。
- 纠纷分类。
- 法律文件全称。
- 发布机关。
- 文号，有则填写。
- 条款号。
- 官方原文。
- 通俗说明。
- 适用范围。
- 适用地区。
- 公布日期。
- 生效日期。
- 失效日期，仍有效则留空。
- 官方来源 URL。
- 来源截图或 PDF，建议保留。
- 来源核验人。
- 来源核验日期。
- 专业复核人。
- 专业复核日期。
- 复核结论。
- 复核意见。
- 下次复审日期。
- 当前状态。

历史导入正文只能放在“旧版法条正文”或迁移备注中，不能替代“官方原文”。

### 5.2 类案

类案至少应具备：

- 案例 ID。
- 案件名称。
- 案号。
- 审理法院。
- 裁判日期。
- 是否终审或生效。
- 来源类型。
- 官方来源 URL 或来源文件。
- 案情摘要。
- 裁判要旨。
- 裁判结果。
- 关联法条 ID。
- 关键证据。
- 脱敏情况。
- 来源核验人。
- 来源核验日期。
- 专业复核人。
- 专业复核日期。
- 复核结论。
- 复核意见。
- 当前状态。

案件摘要和裁判结果必须与原始裁判文书一致。姓名、身份证号、住址、联系方式、未成年人信息等敏感信息必须脱敏。

### 5.3 引用关系

引用关系应至少检查：

- 法条 ID 是否存在。
- 法条是否仍是现行有效版本。
- 法条是否适用于该案争议焦点。
- 裁判文书是否实际引用该法条。
- 是否存在“裁判结果相关，但裁判理由并未引用”的误配。
- 是否存在同一案件引用地方规定、司法解释和上位法时的层级混淆。

ID 存在只是第一层自动校验，不能代替专业相关性复核。

### 5.4 Prompt 与规则

Prompt 复核重点：

- 是否要求模型编造案例、案号、金额或法律结论。
- 是否把个别案例结果写成普遍答案。
- 是否要求固定模板、固定字数或固定 Emoji，导致回答机械。
- 是否保留时效、证据、风险和人工介入提示。
- 是否允许模型明确说“不确定”和“需要补充信息”。
- 是否把法律专业判断隐藏在无法追溯的自然语言中。

### 5.5 帮助资源

帮助资源至少应具备：

- 资源 ID。
- 类型。
- 名称或地区。
- 电话或 URL。
- 原说明。
- 使用范围。
- 最近拨测或访问日期。
- 官方来源 URL。
- 是否可用。
- 来源核验人。
- 专业复核人。
- 复核日期。
- 当前状态。
- 备注。

## 6. 状态流转

| 状态 | 进入条件 | 可执行操作 |
|---|---|---|
| 草稿 | 内容刚导入或退回修改 | 补字段、查来源、修正引用 |
| 来源已核验 | 官方原文、URL、核验人和日期齐全 | 提交专业复核 |
| 待专业复核 | 已进入法学复核队列 | 通过、退回修改或不通过 |
| 复核通过 | 专业复核结论为通过 | 提交发布审批 |
| 已发布 | 发布门禁全部通过 | 定期复审、发现问题后撤回 |
| 已撤回 | 法律修订、案例失效、资源失效或发现重大错误 | 修复后重新走完整流程 |

禁止状态跳级。不能从“草稿”直接改为“已发布”。

## 7. 操作流程

### 7.1 法条核验

1. 在官方来源检索法律文件。
2. 确认正式文件名称、发布机关和文号。
3. 找到目标条款，逐字复制官方原文。
4. 核对公布、生效和失效日期。
5. 判断现行版本是否已被修订。
6. 填写官方来源 URL，并保存页面截图或 PDF。
7. 由来源核验人记录姓名和日期。
8. 由专业复核人复核适用范围、通俗说明和风险边界。
9. 复核通过后提交发布审批。

### 7.2 类案核验

1. 根据案号或案件名称检索裁判文书。
2. 打开法院或官方案例渠道的原始页面。
3. 核对案号、法院、裁判日期和裁判阶段。
4. 阅读裁判理由，提炼裁判要旨。
5. 确认案件实际引用的法条，修正引用关系。
6. 检查是否保留敏感个人信息。
7. 保存裁判文书或官方页面 PDF。
8. 由专业复核人判断案例可比性和表述边界。

若无法找到案号或原始裁判文书，应将内容退回修改或撤回，不能依据新闻摘要补造案号、法院和裁判理由。

### 7.3 引用修复

本复核包中已经标红的引用需要优先处理：

- `cn-work-injury`
- `cn-contract-48`
- `cn-social-58`
- `cn-contract-50`

处理顺序：

1. 判断原意对应的法条。
2. 检查法条库中是否已有正确 ID。
3. 没有时先补充法条，再更新引用。
4. 修正后重新运行引用校验。
5. 由专业复核人确认实体相关性。

### 7.4 帮助资源核验

电话：

1. 使用实际电话拨测。
2. 记录拨测日期和工作时间。
3. 确认接听主体和业务范围。
4. 补齐官方发布页面。

视频：

1. 实际打开链接。
2. 确认发布主体和内容主题。
3. 检查是否仍可播放、是否被删除或转载。
4. 核对内容与当前法律口径是否一致。
5. 必要时替换为更稳定的官方资源。

## 8. 自动校验与人工校验

### 8.1 系统可自动完成

- 必填字段是否为空。
- ID 是否重复。
- 类案引用的法条 ID 是否存在。
- URL 格式是否合法。
- 日期先后关系是否异常。
- 当前状态是否满足发布门禁。
- 内容是否缺少专业复核人、日期或结论。
- 是否长期未复审。

### 8.2 必须人工完成

- 官方原文是否逐字一致。
- 法条是否为现行版本。
- 通俗说明是否改变法律含义。
- 类案是否真正具有可比性。
- 裁判要旨是否准确。
- 引用关系是否具有实体相关性。
- 电话能否拨通、视频能否访问。
- 是否适合向普通用户展示。

## 10. 发布门禁

一条内容同时满足以下条件，才允许进入发布审批：

- 必填字段完整。
- 官方来源可访问。
- 官方原文与来源一致。
- 类案有完整案号和来源。
- 引用关系全部有效。
- 引用实体相关性已由专业复核人确认。
- 来源核验人和日期完整。
- 专业复核人、日期、结论和意见完整。
- 复核结论为“通过”。
- 当前状态为“复核通过”。
- 已填写下次复审日期。

任一条不满足，发布门禁应保持“未通过”。

## 11. 复审与撤回

### 11.1 定期复审

原则上每 6 个月复审一次。以下内容应缩短周期：

- 新近修订或争议较大的法律。
- 地方性规定。
- 新就业形态、工伤、竞业限制等快速变化领域。
- 依赖单一案例或单一来源的结论。
- 电话、视频和在线诉讼入口。

### 11.2 立即撤回条件

出现以下情况时，应立即停止展示并标记“已撤回”：

- 法律被修订、废止或生效版本发生变化。
- 司法解释、地方规定或配套政策发生变化。
- 裁判被撤销、改判或来源无法继续证明。
- 发现法条引用错误或案例事实错配。
- 发现金额、时效或程序提示存在重大误导。
- 帮助电话失效、视频下线或发布主体不可信。
- 发现敏感个人信息未脱敏。

撤回不等于删除历史。应保留撤回原因、操作人、时间和替换内容。

## 12. 审计材料与留存

每条内容应保留：

- 原始来源 URL。
- 页面截图或 PDF。
- 来源文件版本和保存日期。
- 来源核验记录。
- 专业复核意见。
- 发布审批记录。
- 历次修订和撤回记录。

建议审计记录长期保留，至少不应短于内容失效后的平台审计要求。文件名应包含内容 ID、来源类型和日期，避免只保存为“截图1”“资料最终版”。
