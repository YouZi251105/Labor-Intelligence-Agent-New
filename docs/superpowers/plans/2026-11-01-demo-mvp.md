# Demo MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an end-to-end demo covering authentication, roles, cases, multi-turn consultation, evidence assessment, contract review, document generation, lawyer assignment, and admin operations.

**Architecture:** Extend the FastAPI modular monolith with SQLAlchemy domain models and a local SQLite demo database. If a Qwen API key exists, the consultation service calls Qwen; otherwise it uses deterministic demo rules clearly labeled as demo output. Extend the Vue application with authenticated routes and case-centered pages.

**Tech Stack:** FastAPI, SQLAlchemy async, SQLite/aiosqlite for local demo, Argon2, JWT, Vue 3, Pinia, Vue Router, Element Plus, Playwright.

## Global Constraints

- External product language treats this as first-time development.
- Demo credentials must remain development-only.
- AI output is legal assistance, not a final legal opinion.
- Lawyers may only access assigned cases.
- Evidence files cannot be publicly served.
- The full workflow must remain runnable without Docker or an external AI key.
