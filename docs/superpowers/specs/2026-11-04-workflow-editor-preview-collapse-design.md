# 规则包画布预览与折叠设计

## 目标

降低规则包编辑页的信息密度，让管理员可以在完整编辑区和只读预览区之间快速切换，并可独立折叠版本列表、积木面板和属性面板。

## 方案选择

- 继续使用现有受约束 SVG 画布，不在本阶段引入 Vue Flow、LogicFlow 或 X6。
- 当前画布只承担受控节点、受控出口和只读查看，核心诉求是工作区整理，不是自由图编辑。
- 保留后续迁移图编辑器的边界，节点、出口和 `designer` 元数据不改变。

## 编辑与预览

- 画布顶部提供 `编辑` 和 `预览` 分段切换。
- 编辑模式保留积木面板、画布和属性面板。
- 预览模式隐藏积木面板与属性面板，画布占满编辑区域。
- 预览模式禁止拖拽、添加、删除和修改属性，但保留节点选中、连线高亮和悬停出口名称。
- 从编辑切换到预览时自动适应画布；退出预览时恢复 100% 缩放。

## 画布工具栏

- 放大、缩小、适应画布和缩放百分比。
- 自动整理，只读或预览模式下禁用。
- 全屏切换，使用浏览器 Fullscreen API。
- 积木面板和属性面板折叠按钮。
- 工具栏按钮使用 Lucide 图标并提供可访问名称与悬浮提示。

## 折叠策略

- 版本列表折叠为窄栏，只保留展开按钮；重新展开后保持当前选择。
- 积木面板折叠为图标栏，仍可展开；预览模式强制隐藏。
- 属性面板可以单独折叠；选中节点不会自动强制展开。
- 桌面端使用网格列宽切换，移动端保持单列布局。

## 缩放与测量

- 流程平面按缩放比例变换，外层滚动区域使用缩放后的尺寸。
- 积木和出口位置按缩放比例反算，保证拖放、连线和命中区域一致。
- 缩放范围限制在 35% 至 160%。

## 错误与边界

- 浏览器不支持 Fullscreen API 时按钮不改变页面状态。
- 适应画布至少保留 24px 内边距。
- 只读规则包可以进行预览和折叠，但不能进入可写工具状态。
- 规则包内容、校验、Excel 导入导出、审核发布和运行时不改变。

## 验收

- 桌面端可以切换编辑与预览，预览时只显示工具栏和画布。
- 放大、缩小、适应画布、全屏与自动整理可用。
- 三类折叠状态互不干扰，刷新后不要求持久化。
- 手机端工具栏可换行，画布仍可触控滚动。
- 单元测试、类型检查、生产构建和桌面/移动端 Playwright 通过。
