# 劳务通律师使用手册

适用对象：平台内部律师  
版本：0.2.0 Demo

## 1. 登录

演示账号：

- 用户名：`lawyer`
- 密码：`Lawyer123!`

律师账号由管理员维护，当前不开放公开注册。

## 2. 律师工作台

登录后自动进入律师工作台。

工作台包含六个页签：案件、待办、咨询会话、服务记录、律师意见和收益台账。

案件页签只展示管理员已分配给当前律师的案件。可以看到：

- 案件编号
- 案件名称
- 纠纷类型
- 案件摘要
- 用工地点
- 当前阶段
- 最近更新时间

待办和咨询会话页签用于律师服务功能，详见第 4 节。

## 3. 查看案件

点击案件卡片进入案件详情。

律师可以查看：

- 案件概览
- 咨询记录
- 证据材料
- 合同审查页签
- 法律文书

律师访问案件时会经过服务端对象级权限检查。未分配给当前律师的案件不会返回。

## 4. 当前可操作范围

当前 Demo 已支持：

- 查看案件
- 查看问答上下文
- 查看材料列表和缺口提示
- 查看合同风险结果
- 查看和下载文书草稿
- 在“律师意见”页提交专业意见
- 在“服务记录”页登记咨询、证据、文书和出庭服务
- 推进服务记录状态
- 在“收益台账”页创建待确认收入

新增律师服务功能：

### 待办页签

- 受理预约：劳动者提交的律师协助预约出现在“待办”中，可以受理并开始对话或拒绝。受理后案件自动分配给你（若尚未分配），并自动创建咨询会话。
- 立案前复核：案件进入仲裁等正式流程前，劳动者可以申请人工复核。你复核最终材料后提交结论（可以立案 / 需要补充材料 / 暂不建议立案）和意见，提交后案件自动分配给你（若尚未分配）。

### 咨询会话页签

- 受理预约后自动创建会话，点击会话进入对话窗口。
- 双方消息全部留存，劳动者退出后再回来可以继续对话。
- 点击“结束会话”完成本次服务，历史记录保留但不能再发送消息。

律师只能为管理员已经分配给自己的案件提交意见和服务记录。

律师对案件上下文、咨询记录、证据和文书为只读访问，不能代替劳动者发送咨询、上传证据、修改案件事实、推进流程或生成文书。

## 5. 当前限制

以下功能尚未实现：

- 修改 AI 分析结果
- 在线订单、支付、自动分账、提现和评价
- 律师资质上传与审核流程
- 收益状态由管理员确认，律师端不直接结算

## 6. 权限与保密

- 只查看已经分配给自己的案件。
- 不下载、转发或传播与案件无关的材料。
- 不把真实案件材料上传到未经授权的第三方工具。
- 正式运营前应签署保密协议，并配置材料访问审计。

## 7. 常见问题

### 工作台没有案件

请让管理员在“管理后台 → 案件分配”中分配案件。

### 打开案件显示不存在

可能是案件尚未分配、管理员已取消分配，或当前账号无权访问。

### 无法访问管理后台

律师账号不具备管理员权限。
