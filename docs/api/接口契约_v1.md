## 2. 通用规则

### 认证

除注册、登录和健康检查外，请求必须包含：

```http
Authorization: Bearer <access_token>
```

### 内容类型

JSON 请求：

```http
Content-Type: application/json
```

文件上传：

```http
Content-Type: multipart/form-data
```

### 错误

统一结构：

```json
{
  "detail": "错误说明"
}
```

状态码：

| 状态码 | 含义 |
|---|---|
| 200 | 成功 |
| 201 | 创建成功 |
| 400 | 参数、文件或状态不允许 |
| 401 | 未登录或 Token 失效 |
| 403 | 角色无权 |
| 404 | 资源不存在或无权访问 |
| 409 | 用户名或材料重复 |
| 422 | 请求 Schema 校验失败 |
| 500 | 服务端错误 |

### 时间

所有时间字段使用 ISO 8601：

```text
2026-11-01T08:45:51.839044
```

### ID

当前使用整数 ID。前端不得自行推导资源关系。

```json
  "username": "worker01",
```

## 7. 案件与咨询

### POST /cases

权限：已登录

请求：

```json
{
  "title": "工地欠薪咨询",
  "dispute_type": "general",
  "location": "上海市",
  "facts": "在工地工作三个月，老板拖欠工资。"
```

权限：已登录

返回当前角色可访问案件：

- 劳动者：自己的案件。
- 律师：分配给自己的案件。
- 管理员：全部案件。

响应：`CaseRead[]`

## 8. 证据与合同

### GET /cases/{case_id}/evidence

权限：案件所有者、分配律师或管理员。

响应：

```json
{
  "items": [],
  "assessment": {
    "status": "needs_more",
    "required_categories": ["payroll", "chat", "contract"],
    "present_categories": [],

    "missing_labels": ["工资或转账记录", "聊天记录", "合同或协议"],
    "message": "当前材料仍有缺口。",
    "disclaimer": "评估仅用于材料整理。"
  }
}
```

### POST /cases/{case_id}/evidence

权限：案件所有者、分配律师或管理员。

请求：

```text
multipart/form-data
file=<binary>
```

限制：

- 单文件不超过 20MB。
- 支持 jpg、jpeg、png、webp、pdf、txt、doc、docx。
- 文件内容与扩展名必须匹配。
- 同一案件不能上传相同 SHA256 文件。

响应 `201`：`EvidenceRead`

### POST /cases/{case_id}/contract-review

权限：案件所有者、分配律师或管理员。

请求：

```json
{
  "text": "合同全文或关键条款"
}
```

响应：

```json
{
  "risk_level": "high",
  "findings": [
    {
      "level": "high",
      "title": "放弃社会保险条款",
      "detail": "该条款可能影响社会保险权益。"
    }
  ],
  "missing_items": ["工资标准和支付时间"],
  "disclaimer": "不构成合同真实性或法律效力结论。"
}
```

### POST /cases/{case_id}/transitions

权限：案件所有者、分配律师或管理员。

请求：

```json
{
  "target_stage": "procedure",
  "note": "用户确认进入协商"
}
```

规则：

- 只允许服务端批准的相邻转换或符合规则的跳转。
- 条件不满足返回 `400`。
- AI 只能建议，不能直接调用状态转换。
- 成功响应返回最新 workflow。

## 13. 契约变更

1. 先修改本文档。
2. 双方确认字段、枚举和兼容策略。
3. 修改 Pydantic Schema。
4. 运行：

```powershell
cd backend
.\.venv\Scripts\python scripts\export_openapi.py
```

5. 更新前端 TypeScript 类型。
6. 更新 Mock 和测试。
7. PR 中说明变更。

破坏性变更必须使用 `/api/v2`，不得直接在 v1 修改已有字段含义。
